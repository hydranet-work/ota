# OTA server

Custota OTA server for rooted GrapheneOS, komodo (Pixel 9 Pro XL), alpha channel.

Set one of these as the OTA server URL in Custota:

- Magisk: `https://hydranet-work.github.io/ota/magisk`
- Magisk (pixincreate fork, working zygisk): `https://hydranet-work.github.io/ota/pixincreate`
- Rootless: `https://hydranet-work.github.io/ota/rootless`

Generated by the workflows on the `master` branch. Do not edit by hand.
